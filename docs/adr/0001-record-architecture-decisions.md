# ADR 0001: Record Architecture Decisions

Date: 2026-07-25

## Status

Accepted

## Context

Àjọ is a consultancy showcase where the codebase is part of the pitch. Decisions
that affect architecture, contracts, or money flow must be explainable to a
client CTO and discoverable by future implementation sessions.

## Decision

Use ADRs for significant technical decisions and for any deviation from the
backend harness prompt.

## Consequences

- Design intent remains auditable.
- Prompt deviations require explicit rationale.
- Documentation updates are part of the definition of done.
